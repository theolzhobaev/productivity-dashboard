Productivity Dashboard
A clean and modular web dashboard that brings together essential productivity tools in one interface. The project focuses on simplicity, clarity, and practical daily use.
Features
Tasks — Add and manage a personal to‑do list
Pomodoro Timer — Built‑in 25‑minute focus timer with reset option
Notes — Quick note‑taking area
Weather — Check current weather by entering a city name
Theme Switcher — Toggle between light and dark mode

Technologies Used
HTML, CSS, JavaScript
Modular JavaScript structure
LocalStorage for saving tasks and notes
Basic multilingual support (German interface by default)
